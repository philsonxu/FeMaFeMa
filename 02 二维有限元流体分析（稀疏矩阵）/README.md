# Fem2DFluid —— 二维有限元流体分析程序

> **C# 3.0** · **.NET 10.0** · **WinForm** · **Visual Studio 2026** 项目
> 
> 纯C#实现的二维**势流/渗流/稳态导热**有限元求解器，含三角网格自动剖分、DXF几何导入、彩色云图可视化。

---

## 一、功能概览

本程序是一个教学级二维有限元（FEM）桌面应用，求解二维椭圆型偏微分方程——通用控制方程：

```
∇ · ( k ∇φ ) = f     在计算域 Ω 内
φ = φ₀               在第一类(Drichlet)边界 Γᴅ 上
k · ∂φ/∂n = q        在第二类(Neumann)边界 Γɴ 上
```

根据 `k` 和 `φ` 的物理含义，程序可求解三类问题：

| 问题类型 | φ 的含义 | k 的含义 | 典型应用 |
|:--|:--|:--|:--|
| 势流 | 速度势 φ | 1（流体密度相关） | 二维理想流、绕流、管道流 |
| 渗流 | 总水头 H | 渗透系数 k | 坝体渗流、基坑降水、地下水 |
| 导热 | 温度 T | 导热系数 λ | 稳态热传导 |

### 主要功能

- ✅ **节点/单元文本文件导入**（自定义简单格式，可用记事本编辑）
- ✅ **DXF文件几何导入**（支持 Line / LwPolyline / Polyline2D / Circle / Arc）
- ✅ **自动三角网格剖分**（Bowyer-Watson Delaunay 算法 + 多边形边界裁剪）
- ✅ **线性三角单元(CST)**有限元组装 + 列主元高斯消元直接求解
- ✅ 两类边界条件：Dirichlet（给定值）、Neumann（给定法向通量）
- ✅ **计算结果双输出**：CSV/Tecplot DAT 数据文件 + Jet 彩色云图PNG
- ✅ 云图包含**色条图例**、网格线开关、**速度矢量**箭头、边界条件标记
- ✅ **三个完整计算实例**（方腔势流/绕圆柱势流/达西坝体渗流），含数据、图例、结果
- ✅ WinForm 纯代码构建界面（无Designer依赖），代码全部 **不用 `var`**

启动后默认加载**示例1（方腔均匀势流）**：

1. 勾选工具栏 **LT6** 复选框（默认开启）使用六节点二次三角形，取消则使用三节点CST线性单元；
2. 点击工具栏 **🧮 求解** 按钮；
3. 右侧画布实时显示**φ 势函数云图**（线性分布，从蓝到红）；
4. 顶部下拉切换到**Vmag(速度)**视图，可见全场速度均匀（u=1, v=0）；
5. 勾选/取消 **网格/矢量** 可切换显示效果；
6. 菜单 **文件→导出结果CSV / 导出Tecplot DAT / 导出文本报告VTK / 导出云图PNG** 保存结果。
7. 若要做**非稳态时间推进**，设置 Δt（默认0.05s）→ 连续点 **▶ 时间步** 按钮观察势场建立过程。

### 3.3 试算其他示例

- **示例2：绕圆柱势流**：点击工具栏「示例2」→ 设置网格尺寸为 0.20 → 🔺剖分 → 🧮求解；可见圆柱周围流线加速（Vmag 增大）。
- **示例3：达西渗流坝体**：点击「示例3」→ 直接点 🧮求解；φ 等值线从上游10m下降到下游2m。

## 四、输入文件格式

### 4.1 自定义TXT/DAT格式

文本文件以 `#` 开头为注释，分节定义：

```
TITLE 模型标题
PROBLEM 0                 # 0=势流 1=渗流 2=导热
MATERIALS 1               # 材料数量
1 Fluid 1.0 0.0           # id 名称 k 源项f
NODES 4                   # 节点数量
1 0.0 0.0 1 0.0           # id x y bcType bcValue（bcType:0无,1Dirichlet,2Neumann）
2 1.0 0.0 1 1.0
3 1.0 1.0 0 0.0
4 0.0 1.0 0 0.0
ELEMENTS 2                # 三节点单元数量
1 1 2 3 1                 # id n1 n2 n3 matId
2 1 3 4 1
EDGES 0                   # 可选：边界边(会覆盖节点BC)
```

节点按**逆时针方向**排列三角形单元可保证面积为正（程序自动取绝对值，正反均可）。

### 4.2 DXF 几何格式

通过 `netDxf` 库读取，支持以下实体作为外轮廓/孔：

- `Line` 线段
- `LwPolyline` / `Polyline2D` 多段线（自动识别闭合）
- `Circle` 圆（按 36 段近似）
- `Arc` 圆弧（按 10° 一段近似）

导入DXF后：
1. 设置工具栏的**网格尺寸**（建议取几何特征尺寸的 1/20 ~ 1/50）；
2. 点 **🔺 剖分**：程序自动在多边形内部生成结构化点阵，执行 Delaunay 三角剖分并裁剪域外单元；
3. 所有边界节点默认 BCType=1（壁面），若要设置入口/出口 Dirichlet，可先导出TXT、手工修改 BC 列后再重新导入。

## 五、有限元理论要点

### 5.1 单元刚度矩阵

**线性三角单元(CST)**：1点高斯积分，形函数为：

```
N_i = (a_i + b_i x + c_i y) / (2Δ)
b_i = y_j - y_k,   c_i = x_k - x_j     (i,j,k 循环)
```

单元刚度矩阵：

```
Kᵢⱼᵉ = k/(4Δ) · (bᵢbⱼ + cᵢcⱼ)
```

源项载荷：`Fᵢᵉ = f · Δ/3`（集中质量/1点积分精确）。

Neumann边界：常流量 `q` 作用在边界边（长度L）上，等效节点力为 `q·L/2`。

### 5.2 边界条件施加

- Dirichlet：采用**置1法**——将主元置1，其余行列置0，右端项扣除已知值贡献；
- Neumann：自然边界条件在变分形式中**自动满足**（q=0时无需处理），非零q按线积分加入载荷向量。

**二次三角单元(LT6)**：6节点（3角点+3边中点），二次形函数：

采用3点高斯积分（在面积坐标下权重1/3，积分点(2/3,1/6,1/6)循环），收敛阶 O(h³)。
质量矩阵采用行和法集中质量（M_ii = Σ_j M_ij）保证正定性。

### 5.2 求解器与非稳态

- 稀疏存储：刚度矩阵采用 CSR 压缩稀疏行格式；装配阶段使用 COO 三元组， 多线程并行累加；
- 迭代求解：**GMRES(m=30) 重启广义最小残差法**，配合 **ILU0 不完全LU分解**预处理，收敛容差 1e-10；
- 非稳态时间推进：隐式欧拉 ，每步无条件稳定，可观察势场演化过程。

### 5.3 速度后处理

速度由势梯度得到（单元常值）：

```
u = ∂φ/∂x = (b₁φ₁ + b₂φ₂ + b₃φ₃)/(2Δ)
v = ∂φ/∂y = (c₁φ₁ + c₂φ₂ + c₃φ₃)/(2Δ)
|V| = √(u² + v²)
```

云图按单元中心值上色，Jet 色标（蓝→青→绿→黄→红）共 24 级，右侧带完整色条图例。

## 六、三个计算实例说明

### 实例1：方腔均匀势流 `u=1`

- 域：1×1 正方形
- 边界：左入口 φ=0，右出口 φ=1，上下壁面 ∂φ/∂n=0
- 网格：21×21 结构化三角（共 800 单元、441 节点）
- 解析解：φ = x，u = 1, v = 0
- 结果对比：数值解误差 < 1e-12（机器精度），验证求解器正确

### 实例2：绕圆柱势流

- 域：[0,4]×[1] 矩形，中心 (2,0.5) 半径 0.2 圆柱
- 入口 φ=0，出口 φ=4（产生 u≈1 来流），上下壁面+圆柱面 ∂φ/∂n=0
- 网格：h=0.2 自动 Delaunay 三角剖分（约 600+ 单元）
- 结果：圆柱前缘驻点速度=0，圆柱两侧速度明显增大（理论上为2倍来流）

### 实例3：达西坝体渗流

- 域：20m×10m 矩形坝，上游水头 10m，下游水头 4m（下游水位）、底部 2m
- k = 0.001 m/s（黏土渗透系数）
- 结果：等水头线从上游向下游递减，可从 Vmag 读出各点渗流速度

## 十一、FAQ

**Q1：求解报错"未指定Dirichlet边界条件"？**
A：椭圆型方程需要至少一个Dirichlet节点才能确定唯一解，请在节点上设置 BCType=1 并给定值。

**Q2：DXF导入后剖分得到空网格？**
A：请确认DXF外轮廓是**闭合多边形**（多段线请勾选"闭合"或用线段首尾相连）；孔洞需单独闭合。

**Q3：网格越密结果越准吗？**
A：线性三角单元收敛阶为 O(h)，网格密度加倍误差减半；对于有奇点（角点、源汇）问题需要局部加密。

**Q4：速度矢量非常大/方向奇怪？**
A：通常是Dirichlet边界值设置过小/过大或单位不一致造成，检查入口出口的φ差值和几何单位。
